# SizeFitMe

תוסף כרום (Chrome Extension, Manifest V3) שמתאים אוטומטית בין מידות הגוף של המשתמש לבין טבלאות המידות של מוצרי ביגוד באתרי **AliExpress** ו-**SHEIN**, ומדגיש למשתמש את המידה הנכונה עבורו ישירות בדף המוצר.

> גרסה 1.0.0 — זו העלאה ראשונית לגיטהאב. שינויים עתידיים ייכנסו כגרסאות נפרדות.

## מה זה עושה

1. **Onboarding** — בהתקנה נפתח דף קליטה (`onboarding.html`) בו המשתמש מזין גובה, חזה, מותניים, ירכיים, מגדר, יחידת מידה (ס"מ/אינץ'), העדפת פיט (צמוד/רגיל/רפוי) והמידה שהוא בדרך כלל לובש. אפשר לנהל כמה פרופילים (למשל בן/בת זוג, ילדים).
2. **Content Script** (`content.js`) — רץ בדפי מוצר ב-AliExpress ו-SHEIN, מזהה את טבלת המידות של המוצר, משווה מול הפרופיל הפעיל, ומדגיש את המידה המתאימה ביותר (Perfect / Partial / None / No Chart).
3. **Popup** (`popup.html`/`popup.js`) — תפריט מהיר מתוך סרגל הכלים: החלפת פרופיל פעיל, גישה מהירה לעריכת מידות ולפאנל הניהול.
4. **מעקב שימוש** — התוסף שומר לוקאלית ביקורים בדפי מוצר (`productVisits`), אינטראקציות כמו הוספה לעגלה ומשוב "מתאים / גדול מדי / קטן מדי" (`interactions`), לצורך שיפור ההתאמה וניתוח מאוחר יותר בפאנל הניהול.

## מבנה הפרויקט

```
sizefitme/
├── manifest.json          # הגדרות התוסף (MV3), הרשאות, host_permissions
├── background.js          # Service worker — ניהול storage, ניתוב הודעות, שליחה לשרת חיצוני
├── content.js / content.css   # רץ בדפי מוצר, מזהה טבלת מידות ומדגיש התאמה
├── popup.html/js/css      # תפריט התוסף בסרגל הכלים
├── onboarding.html/js/css # אשף קליטת משתמש חדש (תמיכה בעברית/אנגלית)
├── admin.html/js/css      # פאנל ניהול לצפייה בנתונים שנאספו
├── icons/                 # אייקוני התוסף בגדלים שונים
├── images/                # תמונות עזר (man.png / woman.png)
├── crop-people.js         # סקריפט עזר לעיבוד תמונות (Node, sharp)
├── generate-icons.js      # סקריפט עזר ליצירת אייקונים (Node, sharp)
├── package.json           # תלות פיתוח יחידה: sharp (לסקריפטי העזר בלבד)
└── package-lock.json
```

`node_modules/` **לא** נכלל בריפו (ראה `.gitignore`) — הוא תלות פיתוח בלבד (`sharp`) הדרושה רק כדי להריץ את `generate-icons.js`/`crop-people.js`, ולא נחוצה כדי שהתוסף עצמו ירוץ בדפדפן.

## התקנה מקומית (Load Unpacked)

1. שכפל/הורד את הריפו למחשב.
2. אם צריך להריץ את סקריפטי העזר (`generate-icons.js`, `crop-people.js`) — הרץ `npm install` בתוך התיקייה כדי לשחזר את `node_modules`. **לא נדרש** כדי לטעון את התוסף עצמו.
3. פתח את כרום ועבור אל `chrome://extensions`.
4. הפעל **Developer mode** (פינה ימנית עליונה).
5. לחץ **Load unpacked** ובחר את תיקיית הפרויקט (התיקייה שמכילה את `manifest.json`).
6. התוסף ייטען, ותיפתח אוטומטית לשונית Onboarding.

התוסף פעיל רק בדפים תחת:
- `*.aliexpress.com`, `*.aliexpress.us`
- `*.shein.com`

## פאנל ניהול (Admin Dashboard)

הגישה לפאנל הניהול היא דרך התוסף עצמו (`admin.html`), למשל מתוך תפריט ה-popup או ע"י פתיחה ישירה של `chrome-extension://<EXTENSION_ID>/admin.html`.

**התחברות ברירת מחדל:**
```
משתמש: admin
סיסמה: admin
```

⚠️ ראה [אבטחה](#אבטחה--נקודות-לתשומת-לב) — פרטי ההתחברות מוגדרים כרגע ישירות בקוד (`admin.js`) ואינם מהווים הגנה אמיתית.

**מה רואים בפאנל:**
- **סטטיסטיקות כלליות** — סך פרופילים, פילוח לפי מגדר, סך ביקורים, אחוז התאמה.
- **טבלת פרופילים** — לכל פרופיל: שם, מייל, מידות (חזה/מותניים/ירכיים), העדפת פיט, מידה רגילה, תאריך יצירה, סטטוס (פעיל/לא פעיל). ניתן להרחיב כל שורה ולראות:
  - תאריך עדכון מידות אחרון
  - בלוק "Personalization" — כל נתוני הגוף שהוזנו
  - בלוק "Shopping Insights" — טווח מחירים, קטגוריות מובילות, פילוח לפי אתר ואחוז התאמה
  - טבלת הביקורים המלאה של הפרופיל (תאריך, אתר, חנות, קטגוריה, מחיר, קישור למוצר, התאמה, מידה, פער מידות)
- **טבלת ביקורים (Visits)** — כלל הביקורים בדפי מוצר, עם חיפוש חופשי וסינון "התאמות בלבד".
- **טבלת אינטראקציות (Interactions)** — הוספות לעגלה ומשוב משתמש (מדויק / גדול מדי / קטן מדי).
- **ייצוא (Export)** — כפתור שמוריד קובץ JSON עם כל הפרופילים, הביקורים והאינטראקציות (`sizefitme-export-<timestamp>.json`).

כל הנתונים בפאנל נקראים ישירות מ-`chrome.storage.local` של הדפדפן שבו מותקן התוסף — כלומר הפאנל מציג נתונים **מקומיים לאותו דפדפן/מחשב בלבד**, לא נתונים מרוכזים משרת מרכזי (אלא אם הוגדר endpoint חיצוני, ראה בהמשך).

## שליחת נתונים לשרת חיצוני (אופציונלי)

כברירת מחדל כל הנתונים נשמרים רק מקומית בדפדפן. אם רוצים לשלוח את האירועים (ביקורים, פרופילים, אינטראקציות, משוב) לשרת מרכזי, יש להגדיר endpoint באחת משתי דרכים ב-`background.js`:

```js
// אופציה 1 — הגדרה דינמית מתוך קונסול הדפדפן / קוד אחר בתוסף:
chrome.storage.local.set({ apiEndpoint: 'https://your-api.com/events' })

// אופציה 2 — הגדרה קבועה בקוד, בתחילת background.js:
const API_ENDPOINT_FALLBACK = 'https://your-api.com/events';
```

כל אירוע נשלח כ-`POST` עם JSON בפורמט:
```json
{ "eventType": "visit | profile_save | interaction | feedback", "payload": { ... }, "sentAt": 1234567890 }
```

אם השליחה נכשלת (השרת לא זמין וכו'), האירוע נכנס לתור retry מקומי (`apiRetryQueue`, עד 200 פריטים) וינסה להישלח שוב באתחול הדפדפן הבא.

## אחסון נתונים

כל הנתונים נשמרים ב-`chrome.storage.local` (מקומי לדפדפן, לא מסונכרן בין מכשירים):

| מפתח | תוכן |
|---|---|
| `profiles` | מערך כל הפרופילים (כולל soft-delete עם `deleted: true`) |
| `activeProfileId` / `userProfile` | הפרופיל הפעיל הנוכחי |
| `productVisits` | עד 200 ביקורים אחרונים בדפי מוצר |
| `interactions` | עד 1000 אינטראקציות אחרונות (עגלה, משוב) |
| `feedback` | משוב מפורט שנשלח מהמשתמש |
| `apiEndpoint` | כתובת שרת חיצוני (אופציונלי) |
| `apiRetryQueue` | תור נסיונות שליחה שנכשלו |

## סקריפטים

- `npm install` — מתקין את `sharp` (נדרש רק לסקריפטי עזר).
- `node generate-icons.js` — מייצר את קבצי האייקונים בתיקיית `icons/`.
- `node crop-people.js` — עיבוד/חיתוך תמונות ב-`images/`.

## אבטחה — נקודות לתשומת לב

- **פרטי הכניסה לפאנל הניהול (`admin`/`admin`) שמורים כטקסט גלוי בקובץ `admin.js`** — זה קוד צד-לקוח, כל מי שמריץ את התוסף יכול לראות אותם דרך "View Page Source" של `admin.html`. זו לא הגנה אמיתית, רק חסם בסיסי מפני לחיצה בטעות. אם בעתיד יאוחסנו בפאנל נתונים רגישים (מיילים, מידות אישיות) כדאי לשקול אימות אמיתי (למשל דרך שרת) לפני שימוש מול משתמשים אמיתיים.
- אם מגדירים `apiEndpoint` לשרת אמיתי — יש לוודא שהשרת מאמת/מסנן קלט, מכיוון שה-payload נשלח ישירות מהתוסף ללא חתימה.
